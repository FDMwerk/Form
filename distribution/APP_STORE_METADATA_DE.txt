Beschreibung:
Form gibt deinen 3D-Modellen Raum. Öffne CAD- und 3D-Dateien direkt auf deinem Mac, drehe sie frei und blende einzelne Bauteile ein oder aus. Eine reduzierte Oberfläche, ein fein auslaufendes Grid und eine übersichtliche Bauteilliste helfen dir, dich auf die Form zu konzentrieren.

• Mehrere Modelle und Baugruppen gemeinsam ansehen
• STEP, IGES, BREP, STL, OBJ, PLY, 3MF und eingebettetes glTF/GLB öffnen
• Dateiinformationen, Außenmaße, meshbasiertes Volumen und Zwei-Punkt-Messung anzeigen
• Druckzeit als gekennzeichnete geometrische Näherung einschätzen
• Optional Originaldateien an passende installierte Apps übergeben
• Modelle und Bauteile verschieben, drehen und an äußeren Begrenzungsflächen ausrichten
• Explosionsansichten und verstellbare Schnittansichten
• Texturierter Referenzapfel für einen anschaulichen Größenvergleich
• Lokal und ohne Benutzerkonto, Werbung oder Modell-Uploads
• Originalfarben und eingebettete Texturen, wählbare Standard- und Bauteilfarben
• Vertraute Mausprofile für Bambu Studio, Fusion 360, Blender, SOLIDWORKS und Onshape
• Kostenlos mit offenem Anwendungscode

Messungen erfolgen auf der Darstellungsgeometrie. Einheitenlos gespeicherte Dateien benötigen eine passende Einheitenwahl. Schnittansichten erzeugen keine neuen Volumenkörper. Transformationen gelten für die laufende Sitzung; Originaldateien bleiben unverändert. Form ist ein Viewer mit Anordnungswerkzeugen, keine parametrische CAD-Konstruktion.

Review notes (English):
Form is a free local CAD viewer with no account, in-app purchase, advertisement, analytics, or remote model processing. Use the supplied original demo STL models to inspect the viewer, file information sidebar, measurements, transformations, bounding-face docking, explosion and section views. Verified closed meshes receive filled display caps with holes preserved; open or ambiguous meshes show contours only. Caps do not create exported CAD geometry. The network-client entitlement supports the WKWebView architecture; the app bundles its resources and its Content Security Policy restricts external origins. The Tripo-created reference apple is bundled; no Tripo access or generation occurs in the app. Original model files are read-only. This submission candidate must use the AppStore build configuration (FORM_APP_STORE). It compiles out the desktop Blender Python import adapter and Bambu CLI execution adapter; their actions are not available in the Store UI. The self-contained viewer, labelled geometric printing-time estimate and standard original-document Open With handoff remain available. Blender is excluded from that menu without its importer. No slicer, Python runtime or external engine is downloaded or installed by the Store build. The native donation action is also compiled out and unavailable in this Store flavor. The optional FDMwerk link opens a website for physical printing; it does not upload the selected model. Feature requests open the user’s email client or a public GitHub issue composer, with no automatic submission or model attachment. Desktop Release functionality must not be advertised as a feature of this Store build. LGPL components ship as replaceable resources; exact-source links and release source archives must be supplied before submission.
